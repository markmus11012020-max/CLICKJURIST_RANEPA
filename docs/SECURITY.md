# ClickJurist Production — Соответствие 152-ФЗ

## Принципы

1. **Персональные данные не покидают контур РФ.** Маскировка выполняется российской моделью (YandexGPT/Ollama) либо локальными regex-страховками.
2. **Сырой текст запроса никогда не сохраняется** (в БД и логах).
3. **Идентификация сессии** — необратимый `SHA-256(IP + fingerprint + SESSION_HASH_SALT)`.
4. **Квота дублируется** сетевым ключом `SHA-256("ip-level|" + IP + SALT)`: отпечаток браузера приходит из клиентского заголовка, поэтому одного браузерного ключа недостаточно — смена заголовка не должна выдавать новый бесплатный запрос.
5. **Логи содержат только UUID сессии** (UUIDv5 от хеша), не IP и не fingerprint.
6. **Секреты шифруются Yandex KMS**, расшифровываются только в памяти приложения.

## Технические меры

- `backend/security.py` — хеширование сессий, извлечение IP с учётом прокси.
- `backend/services/pii_masker.py` — двухуровневая маскировка (LLM + regex).
- `backend/logging_setup.py` — `PIIRedactingFilter` страхует любой лог.
- `backend/yandex_kms.py` — белый список секретов для KMS.
- `backend/db.py` — ни одного текстового поля для ПДн в схеме БД.

## Аудит

- `/api/stats` — агрегаты без ПДн.
- `/api/legal` — публичный дисклеймер сервиса.
