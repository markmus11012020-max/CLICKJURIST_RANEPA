# ClickJurist Production — Roadmap

## v2.0.0 (текущая)

- Двухэтапный мегапайплайн (LLM-1 → LLM-2).
- Контур маскировки ПДн в РФ (YandexGPT/Ollama/regex).
- Web-фактчекинг (2–3 источника) с правилом конфликта данных.
- Failover-оркестратор (aitunnel ↔ yandex).
- Robokassa (создание счёта, Result/Success/Fail URL).
- Платёжный барьер: первый запрос бесплатный, далее — 402.
- PDF-версия консультации (кириллица, reportlab).
- Zero-Storage Logging → Yandex Cloud Logging.
- Yandex KMS для секретов.

## v2.1 (план)

- Расширенные типы документов (заявление в полицию, трудовой договор).
- Голосовой ввод на фронтенде (Web Speech API).
- Экспорт результатов в Telegram-бот.
- Личный кабинет юриста: история платежей, избранное.

## v3.0 (стратегия)

- RAG по базе КонсультантПлюс / Гарант.
- Автоматическое формирование пакета документов для суда.
- Интеграция с Госуслугами (отправка жалоб).
